# 📋 مُنظم المهام اليومية | Daily Task Manager

تطبيق ويب تفاعلي وعصري لإدارة وتنظيم المهام اليومية بسهولة واحترافية.

## 🌟 المميزات الرئيسية

### ✨ إدارة المهام
- ✅ **إضافة المهام**: إضافة مهام جديدة بسهولة وسرعة
- ✏️ **تعديل المهام**: تحرير نص المهام الموجودة
- 🗑️ **حذف المهام**: حذف المهام الفردية أو المكتملة أو جميع المهام
- ☑️ **تحديد الإكمال**: وضع علامة على المهام المكتملة

### 🎯 التصفية والتنظيم
- 📝 **عرض الكل**: عرض جميع المهام
- ⏳ **المهام النشطة**: عرض المهام غير المكتملة فقط
- ✅ **المهام المكتملة**: عرض المهام المكتملة فقط

### 📊 الإحصائيات
- عداد إجمالي المهام
- عداد المهام النشطة
- عداد المهام المكتملة

### 💾 التخزين والأمان
- 🔒 **تخزين محلي آمن**: حفظ المهام في localStorage
- 🛡️ **حماية من XSS**: تنظيف المدخلات وحماية من الهجمات
- ✔️ **التحقق من البيانات**: التحقق من صحة المدخلات

### 🎨 التصميم
- 🌈 **تصميم عصري**: واجهة جذابة مع تدرجات لونية
- 📱 **متجاوب تماماً**: يعمل على جميع الأجهزة والشاشات
- ⚡ **تأثيرات سلسة**: انتقالات وحركات ناعمة
- 🌙 **تجربة مستخدم ممتازة**: سهل الاستخدام وبديهي

## 🚀 البدء السريع

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- لا حاجة لخادم - يعمل مباشرة من الملفات

### التثبيت والتشغيل

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd sandbox
```

2. **فتح التطبيق**
   - افتح ملف `index.html` مباشرة في المتصفح
   - أو استخدم خادم محلي:

```bash
# باستخدام Python
python -m http.server 8000

# باستخدام Node.js
npx http-server

# باستخدام PHP
php -S localhost:8000
```

3. **الوصول للتطبيق**
   - افتح المتصفح وانتقل إلى: `http://localhost:8000`

## 🎯 كيفية الاستخدام

### إضافة مهمة جديدة
1. اكتب نص المهمة في حقل الإدخال
2. اضغط على زر "إضافة" أو Enter
3. ستظهر المهمة في القائمة

### تحديد مهمة كمكتملة
- انقر على مربع الاختيار بجانب المهمة
- ستظهر المهمة بخط مشطوب

### تعديل مهمة
1. انقر على أيقونة القلم ✏️
2. عدّل النص في النافذة المنبثقة
3. اضغط "حفظ"

### حذف مهمة
- انقر على أيقونة سلة المهملات 🗑️
- أكد عملية الحذف

### تصفية المهام
- استخدم أزرار التصفية في الأعلى:
  - **الكل**: عرض جميع المهام
  - **النشطة**: المهام غير المكتملة
  - **المكتملة**: المهام المكتملة

### حذف متعدد
- **حذف المكتملة**: يحذف جميع المهام المكتملة
- **حذف الكل**: يحذف جميع المهام (مع تأكيد)
